# Issue tracker: Local Markdown

Specs and issues live under `.scratch/<feature>/` in this repository.

- Keep one spec at `.scratch/<feature>/spec.md`.
- Store numbered tickets at `.scratch/<feature>/issues/NN-<slug>.md`.
- Use the tracker and status conventions already present in a feature folder. For new triageable tickets, use the labels documented in `triage-labels.md`.
- Read referenced files directly; create new tickets in the matching feature folder.
- Wayfinder decision tickets may use `Type`, `Status: claimed/resolved`, and `Blocked by` fields, with resolved decisions recorded in that feature's `map.md`.
- Append issue discussion under `## Comments`; do not rewrite existing history.
